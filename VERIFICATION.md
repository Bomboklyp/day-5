# Проверки пятого дня

Проект проверяется на Windows с Node.js 24.22.3, Nuxt 4, PostgreSQL 18.7 и Chrome. Описание дефектов и их связь с тестами — в `BUGS.md`.

## Команды

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

В проверку типов включены приложение и тестовые файлы. ESLint использует конфигурацию Nuxt; допустимое число предупреждений — ноль. Vitest проверяет unit-правила и composables в окружении Nuxt. Playwright проверяет собранный сервер и PostgreSQL.

Проверяются 17 unit/integration-сценариев и 9 E2E-сценариев. Машинный итог текущего полного прогона копируется в `verification-result.json`; подробный JSON Playwright находится локально в `.verification/day5/e2e-result.json`.

## Воспроизводимость

- Каждый E2E-тест начинается с чистой SQL-схемы, seed-данных и нового браузерного контекста.
- Сервер работает локально на 3105. Тестовая схема удаляется после завершения, рабочая база пятого дня не затрагивается.
- Порядок ответов задаётся явно. Старый поиск удерживается до показа нового; ответ комментария заменяется ошибкой уже после реального сохранения в PostgreSQL.
- Debounce проверяется виртуальными таймерами. E2E ждёт наблюдаемое состояние или конкретный HTTP-ответ, а не произвольное время.
- Автоматических повторов упавших тестов нет. Figma и внешние API не участвуют в критическом прогоне.

## Что проверено

Полный путь пользователя: login → create request → assign → change status → comment → logout. После выхода проверяются история браузера, прямая ссылка и отказ API с кодом 401.

Регрессии: двойной submit; повтор после потери ответа и refresh; два параллельных POST с одним UUID; поздний ответ поиска; поздняя проверка сессии; восстановление черновиков, URL и настроек; соответствие списка фильтру после мутации; сообщения полей формы.

Ошибки: 500 сохраняет форму для повтора; 401 переводит на вход; 409 откатывает оптимистическое изменение и позволяет загрузить актуальную запись. Серверные проверки ролей, статусов, неактивного исполнителя и сохранения данных после перезапуска также входят в прогон.

Снимки 5.01, 5.02 и 5.03 сверяются с тремя экспортами пятого дня. Ошибка формы дополнительно проверяется на 360 и 768 px; desktop — 1280 px. Снимки текущего прогона находятся в папке `Скриншоты`.

Исходный тест гонки `refreshSession/logout` был запущен до исправления и падал: поздний ответ возвращал пользователя вместо `null`. Во время браузерной проверки также обнаружилась очередь watcher поиска; регрессия теперь проверяет два изменения после начальной загрузки.

Архив содержит исходники, SQL, тесты и инструкции. `.env`, пароли подключения, зависимости, сборки, служебные логи и документы других учебных работ в архив не включаются.
